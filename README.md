# sUAS-YOLO-MambaLCT

This repository contains text files that indicate the training and validation sequences used for training and testing YOLO, MambaLCT, and OSTrack models. The original dataset can be downloaded from the following link: https://modelscope.cn/datasets/ly261666/3rd_Anti-UAV/files. After downloading, the sequences can be separated into the appropriate splits based on the provided text files.
